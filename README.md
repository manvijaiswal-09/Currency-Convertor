# 💱 Currency Converter

A simple and responsive web application that allows users to convert an amount from one currency to another using real-time exchange rates fetched from an API.

🔗 *Live Demo:* [View Project](https://manvijaiswal-09.github.io/Currency-Convertor/)

## ✨ Features

- 💱 Convert between different currencies
- 🌐 Uses an API to fetch exchange rates
- 🔄 Swap source and target currencies
- 💰 Enter any amount for conversion
- ⚡ Displays converted amount instantly
- 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Exchange Rate API

## 📚 Concepts Used

- API Integration
- Fetch API
- JavaScript Functions
- DOM Manipulation
- Event Handling
- JSON Data Handling
- Async/Await
